# AnotherMarkdown RU

Форк [ezyuzin/NppAnotherMarkdown](https://github.com/ezyuzin/NppAnotherMarkdown),
основанный на опубликованной версии **0.1.12**. Лицензия MIT сохранена.

## Чтение и перевод

1. Откройте `.md` или `.mdc` в Notepad++ и включите панель AnotherMarkdown.
2. Нажмите **Перевести**. После завершения запроса в панели появится русский текст.
3. **Оригинал** возвращает исходный предпросмотр. **Отмена** останавливает выполняющийся CLI и его дочерние процессы.

Во время запроса в панели вращается значок рядом с кнопкой «Перевести». Это индикатор ожидания,
а не процент выполнения: CLI не сообщает точный прогресс. После завершения,
ошибки, отмены или смены исходного документа индикатор скрывается.

Исходный буфер и файл не изменяются. В переведённом предпросмотре отключены
изменение чекбоксов, вставка изображений и синхронизация строк с редактором.
Редактирование исходника или переход к другому файлу отменяет текущий запрос.
Повторный перевод того же текста с теми же настройками берётся из памяти
(до 8 документов / 4 млн символов суммарно). При закрытии Notepad++ кэш исчезает.

Файлы `.mdc`, включая Cursor Rules, обрабатываются тем же Markdown-рендерером,
что и `.md`. Регистронезависимые расширения, CSS, плагины Markdown и относительные
ссылки работают одинаково. YAML front matter передаётся переводчику с указанием
оставить его без изменений; содержимое правила рассматривается как текст,
а не как команды для агента.

## Настройки

Откройте **Плагины → AnotherMarkdown → Settings → Перевод** либо нажмите
**Настройки перевода** в панели.

- **CLI** — список найденных установок. Поиск проверяет `PATH` и обычные каталоги
  установки, ничего не устанавливая и не запуская остальные CLI. **Выбрать…**
  открывает каталог текущего исполняемого файла. Поддерживаются `.exe` и штатные
  Windows-запускатели `.cmd` / `.bat`. На каждый CLI предлагается одна установка:
  нативный EXE имеет приоритет перед скриптовым запускателем; алиасы `agent` и
  `cursor-agent` объединяются. **Найти CLI** повторяет поиск.
- **Модель** — доступные модели выбранного CLI. **Обновить** повторяет запрос.
  **Модель по умолчанию в CLI** использует настройки самого CLI без передачи
  `--model`. В начальной конфигурации Codex выбрана `gpt-6-astra`.
- **Усилие (effort)** — уровни рассуждения выбранной модели. Для Codex они берутся
  из `model/list`; выбор передаётся через `model_reasoning_effort` только этому
  запросу. **По умолчанию в CLI** сохраняет настройку самого Codex. Для Cursor
  уровни выделяются из реально полученных вариантов моделей: например, Grok 4.7
  и Extra High передают точный ID `grok-4.7-xhigh`. Fast остаётся отдельным
  вариантом модели. Неподдерживаемые уровни не добавляются; для Auto и CLI без
  сведений об effort выбор отключён. При ручных аргументах effort задаётся в них.
- При выборе другого CLI сразу применяются его стандартные параметры и
  загружаются его модели. **Настройки по умолчанию** повторно применяет настройки
  выбранного CLI, включая модель по умолчанию и тайм-аут 300 секунд.
- **Дополнительные параметры** раскрывает тип CLI, тайм-аут (10–3600 секунд),
  необязательный ручной идентификатор модели, аргументы и формат ответа.
  Аргументы редактируются только после включения **Изменить параметры запуска**.
- **Показывать кнопки перевода в панели** управляет кнопками независимо от
  остальных инструментов предпросмотра.

Изменения сохраняются кнопкой **Сохранить**. **Отмена** оставляет прежние настройки.
Долгий запрос списка моделей можно прервать закрытием окна или выбором другого CLI;
ответ старого запроса не подменит новый список.

Плагин использует существующую авторизацию CLI. Предварительно войдите в выбранный
CLI обычным способом. API-ключи в настройках плагина не нужны.

### Поддерживаемые профили

| CLI | Список моделей | Запрос перевода |
| --- | --- | --- |
| Codex CLI | `app-server`: `model/list`, настроенная модель из `config/read` | `exec`, UTF-8 stdin, временный файл результата |
| Cursor Agent | `agent models` | `--print --mode ask --output-format json`, UTF-8 stdin |
| Claude Code | Публичный список через CLI не поддерживается; доступна настроенная модель | `--print`, отключённые инструменты и пустой MCP-конфиг |
| Gemini CLI | Настроенная модель; при необходимости ручной ID | JSON-ответ, plan, временная политика запрета инструментов |
| OpenCode | `opencode models` | `--pure run --format json --agent plan`, запрет инструментов через окружение |
| Ollama | `ollama list` — уже установленные модели | `run --nowordwrap`, первая установленная либо выбранная модель |
| DeepSeek Harness (`dsh`) | Модель из профиля самого DSH | `--profile headless`, запрос аргументом |
| Qwen Code | Настроенная модель; при необходимости ручной ID | UTF-8 stdin, safe mode / plan, JSON-массив с итоговым ответом |
| Kimi Code (новый native CLI) | `provider list --json`, только алиасы из `models` | `-p`, JSONL, временный агент без инструментов и субагентов |
| Antigravity CLI (`agy`) | `agy models` | `--print`, запрос аргументом, JSON с проверкой статуса |
| GitHub Copilot CLI | Настроенная модель; при необходимости ручной ID | UTF-8 stdin, silent, запрет основных категорий инструментов |

Штатные Windows-запускатели Cursor Agent, Qwen Code и DeepSeek Harness могут
быть `.cmd`. Они запускаются скрыто с перенаправлением ввода и вывода; отдельное
окно консоли не открывается. У Antigravity и нового Kimi Code есть нативные EXE.
Профиль Kimi относится к новому Kimi Code; старый Python-проект `moonshotai/kimi-cli`
имеет другой протокол и при необходимости настраивается как **Другой CLI**.

DSH, Kimi Code и AGY получают запрос аргументом. Для них действует ограничение
командной строки Windows: при превышении безопасного порога 30 тысяч символов
плагин выдаст ошибку до запуска. Для больших документов используйте профиль со stdin,
например Codex. DSH использует модель из своего профиля и не принимает общий `--model`.
Для `.cmd` / `.bat` предел ниже — 8 тысяч символов командной строки. Кавычки,
переносы строк и символы `%`, `!`, `^` в аргументах через произвольный batch-launcher
отклоняются до запуска, чтобы не исказить запрос при повторном разборе оболочкой.
На UTF-8 stdin это ограничение не распространяется: Cursor и Qwen передают туда
полный документ. Для профилей с `{prompt}` и многострочных документов нужен EXE.

Живые проверки выполнены **только с Codex и Cursor**, включая штатный запуск
Cursor через `.cmd`, получение моделей и effort. Остальные профили
реализованы по официальной документации; сами CLI для этих проверок не устанавливались
и не запускались. Их поведение зависит от установленной версии. Для Gemini
`--admin-policy` может игнорироваться при наличии системной административной политики.
Для AGY используются существующие разрешения самого CLI; модель получает инструкцию
не пользоваться инструментами. Полное отключение всех инструментов в этом профиле
не заявляется. Все запросы запускаются в отдельном временном рабочем каталоге.

Codex получает документ через UTF-8 stdin и использует `--output-last-message`,
`--ephemeral`, режим `read-only`, отключённые shell, браузер, плагины и инструкции
проекта. Имена MCP-серверов читаются через `config/read`, после чего серверы отключаются
параметрами этого запуска. Если прочитать конфигурацию не удалось, запрос перевода
не запускается. Имена MCP-серверов с точкой не поддерживаются этим способом.
Настройки CLI и его авторизация на диске не изменяются.

Источники профилей: [Codex](https://learn.chatgpt.com/docs/non-interactive-mode),
[Codex app-server](https://learn.chatgpt.com/docs/app-server),
[Cursor](https://cursor.com/docs/cli/overview),
[Claude Code](https://code.claude.com/docs/en/cli-reference),
[Gemini](https://geminicli.com/docs/cli/headless/),
[политики Gemini](https://geminicli.com/docs/reference/policy-engine/),
[OpenCode](https://opencode.ai/docs/cli/), [Ollama](https://docs.ollama.com/cli),
[DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness/tree/master/apps/cli/reference),
[Qwen Code](https://qwenlm.github.io/qwen-code-docs/en/users/features/headless/),
[Kimi Code](https://www.kimi.com/code/docs/en/kimi-code-cli/reference/kimi-command.html),
[Antigravity](https://antigravity.google/docs/cli/headless/),
[GitHub Copilot](https://docs.github.com/en/copilot/reference/copilot-cli-reference/cli-programmatic-reference).

Для **Другой CLI** укажите собственные аргументы. Запрос передаётся через UTF-8 stdin;
ответ читается из stdout либо `{output}`. Подстановки `{model}`, `{output}`, `{config}`
и `{policy}` заключаются в кавычки автоматически. `{prompt}` передаёт полный запрос
аргументом вместо stdin; `{agent}` содержит временный Markdown-агент Kimi.
`{config}` содержит пустой MCP-конфиг
Claude, `{policy}` — политику Gemini. Формат ответа выбирается отдельно: текст,
JSON с `result`, JSON с `response`, события OpenCode, AGY или Kimi.
Запускатель должен иметь расширение `.exe`, `.cmd` или `.bat`.

Настройки сохраняются в секции `[Translation]` стандартного `AnotherMarkdown.ini`
в каталоге конфигурации плагинов Notepad++. Они переживают перезапуск редактора.

Перевод выполняется выбранной моделью и может содержать неточности. Кодовые блоки,
пути, идентификаторы и разметка сохраняются по инструкции модели; для сверки
используйте **Оригинал**.

## Установка

Закройте Notepad++. Сохраните резервную копию папки плагина, затем распакуйте
`AnotherMarkdown-0.1.12-ru.3-x64.zip` в `Notepad++\plugins\AnotherMarkdown`.
Если меняли CSS или другие assets, сохраните свои версии отдельно.
Сборка предназначена для **64-битного Notepad++**. Для отката закройте редактор
и восстановите папку из резервной копии.

Обновление AnotherMarkdown через Plugin Admin заменит форк официальной сборкой;
для сохранения кнопки перевода устанавливайте сборки этого форка.

## Сборка и проверки

Требуются Windows, Python 3 и Visual Studio Build Tools с MSBuild/Roslyn.

```powershell
powershell -ExecutionPolicy Bypass -File .\build_tools\build-translation.ps1
```

Скрипт получает закреплённые версии NuGet-пакетов и готовые JS-ресурсы официального
релиза 0.1.12, собирает x64 DLL, запускает тесты и создаёт ZIP в `Release`.
Кэш и промежуточные файлы находятся вне исходников. Каталоги можно задать через
`-CacheRoot` и `-OutputDirectory`.

Экспорт шести функций ABI Notepad++ выполняется через Microsoft ILDasm/ILAsm;
устаревшая задача сборки, требовавшая .NET 2.0, в этом скрипте не используется.
Проверки покрывают UTF-8, кавычки, файл результата, ошибки, отмену, дочерние процессы,
тайм-аут, кэш, пагинацию моделей, JSON-ответы и сохранение полей настроек.
Реальные запросы выполняются отдельно в каталоге кэша сборки:

```powershell
.\TranslationTests.exe models-real   # Только Codex и Cursor
.\TranslationTests.exe real          # Перевод через Codex / gpt-6-astra
.\TranslationTests.exe real cursor   # Перевод через Cursor / Grok 4.7 Extra High
.\SettingsTests.exe live-ui          # Codex/Cursor, effort, defaults, снимки
```

Запросы перевода используют авторизацию и лимиты соответствующего CLI.
