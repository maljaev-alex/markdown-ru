# Визуальный редактор Markdown

Панель использует CKEditor 5 с русской панелью инструментов, похожей на редактор
OpenProject. В файле остаётся обычный Markdown + GFM. HTML для оформления не создаётся.

## Редактирование и сохранение

Откройте сохранённый `.md` или `.mdc` и включите панель Markdown. Файл открывается
в режиме просмотра, инструменты форматирования скрыты. Нажмите **Редактирование**
в верхней строке, чтобы включить WYSIWYG.
Панель можно расширить или открыть отдельным окном двойным нажатием на её заголовок.
Можно править исходник в Notepad++ либо текст в визуальном редакторе:
изменения автоматически переходят в другую сторону после короткой паузы ввода.
Файл на диске записывается штатными средствами Notepad++: **Сохранить** либо **Ctrl+S**.
Отдельной кнопки сохранения оригинала в панели нет.
До сохранения действует обычная отметка изменённого буфера Notepad++.
Undo/Redo доступны в обоих редакторах; обновление из исходника сбрасывает локальную
историю визуального редактора, история Notepad++ сохраняется.

Кнопка **Просмотр** возвращает прежний рендерер с настроенными расширениями Markdown,
формулами, Mermaid и просмотром изображений. Переключение на другой документ снова
открывает просмотр. Действия редактора находятся в одной верхней строке с переводом
и настройками; статус синхронизации прижат к правому краю.
Кнопка **М** на панели Notepad++ нажата, пока окно Markdown открыто.

При переходе на файл другого типа панель автоматически скрывается. Возврат
на `.md` или `.mdc` восстанавливает её, если она была включена. После ручного
закрытия панель сама не открывается.
Состояние включения сохраняется между запусками Notepad++: на восстановленной
Markdown-вкладке панель открывается автоматически. Если активен файл другого типа,
она появится при переходе на Markdown. Автоматическое скрытие не сбрасывает этот выбор.
Рядом с **М** находятся кнопки **Назад по файлам** и **Вперёд по файлам**.
Они переходят по истории посещённых вкладок всех типов, пропуская закрытые.
Новый переход после возврата назад очищает ветку истории вперёд.

Курсор, выделение текста и прокрутка синхронизируются в обе стороны в просмотре
и WYSIWYG. Фокус остаётся в активной панели; в просмотре позиция курсора обозначается
тонкой кареткой. При работе в рендере каретка также видна в неактивном исходнике;
её цвет соответствует теме Notepad++, ввод остаётся в рендере. Сохраняется направление
выделения. В меню плагина доступны независимые
переключатели **Синхронизировать курсор и выделение** и **Синхронизировать прокрутку**;
по умолчанию оба включены. Обновление с прежних версий включает новую синхронизацию;
далее выбор сохраняется в INI (`SyncCaretAndSelection`, `SyncScrollBothWays`).

Привязка учитывает Markdown-разметку, таблицы, кириллицу и Unicode. Для невидимых
маркеров Markdown используется ближайшая позиция отображаемого текста, для изображений
и защищённых блоков — граница блока. Из-за разной ширины и высоты строк панели
выравниваются по соответствующему тексту, а не по проценту полосы прокрутки.
Синхронизируется основной непрерывный диапазон выделения; дополнительные курсоры
и прямоугольное выделение Notepad++ не воспроизводятся как отдельные диапазоны в рендере.
Навигация не меняет Markdown, не записывает файл и не добавляет шагов Undo.
Устаревшие события другой вкладки или версии текста игнорируются; при конфликте
синхронизация навигации приостанавливается до его разрешения. В переводе она отключена.

**Настройки** открываются на первой странице **Просмотр**. Поле **Тема** позволяет
выбрать светлую, тёмную или **Как в Notepad++**. Выбор сохраняется между запусками.
В просмотре используются прежние CSS-файлы; тёмный редактор показывает светлый текст
на фоне `#1e1e1e`, светлый — тёмный текст на белом фоне.

Опция **Показывать адреса ссылок** управляет подсказкой при наведении
на ссылку или её выборе с клавиатуры. Переключение применяется сразу, без
перезагрузки страницы и сброса режима редактирования. Отдельной нижней строки состояния у панели нет; документ занимает
всю доступную высоту. Статус синхронизации остаётся в верхней строке с кнопками.

Локальные ссылки открываются в Notepad++ без ограничения по расширению, включая
`.bsl`, `.json` и `.xml`. В просмотре достаточно обычного клика. В редакторе
используйте **Ctrl+клик**, **Alt+Enter** либо кнопку перехода во всплывающей панели
ссылки; обычный клик позволяет её отредактировать.
Поддерживаются относительные пути, пути вида `D:/...` и `file:///...`.
Суффиксы `:6531` и `:6531:7` задают строку и столбец, начиная с единицы.
Путь и номер позиции сохраняются в исходном Markdown, а подсказка показывает
читаемый адрес с кириллицей.

## Формат

На странице **Настройки → Просмотр** есть опция **Сохранять переносы строк в редакторе**.
По умолчанию она выключена: обычные переносы внутри Markdown-абзаца отображаются
как пробелы, и текст заполняет ширину панели. При включении редактор показывает
каждую строку исходника отдельно. Настройка меняет отображение и сохраняется в INI
(`PreserveEditorLineBreaks`); переключение не переписывает исходный Markdown.
Явные разрывы (два пробела или обратная косая черта перед концом строки), абзацы
и строки блоков кода сохраняются в обоих режимах. **Shift+Enter** вставляет явный
разрыв, совместимый с обычными просмотрщиками Markdown.

Доступны заголовки, полужирный и курсивный текст, зачёркивание, ссылки, изображения,
обычные и нумерованные списки, задачи с чекбоксами, цитаты, разделители, inline-код,
блоки кода и GFM-таблицы. Выравнивание существующих столбцов таблицы сохраняется.
Цвета, размеры шрифта, объединение ячеек и другие функции, требующие HTML,
в панели отсутствуют. При вставке форматированного текста остаётся поддерживаемое оформление.

Нетронутые блоки сохраняют исходную запись, включая переводы строк и способ выделения.
Правки текста переносятся в исходную запись: сохраняются маркеры списков, пробелы,
пустые строки, разделители выделения, ссылочная запись и отступы в таблицах.
Результат проверяется повторным разбором в редакторе. Если изменение структуры
нельзя перенести с сохранением смысла, изменённый блок сериализуется в Markdown заново.
YAML front matter, уже существующий HTML и распознанные расширения вне GFM отображаются
как защищённые блоки с исходным текстом. Их можно править в Notepad++; соседние визуальные
правки их не переписывают. Существующий HTML в предпросмотре показывается как текст,
его обработчики событий не выполняются. Код Mermaid редактируется как блок кода, диаграмма видна в предпросмотре.

При вставке или загрузке картинки в оригинал файл создаётся рядом с документом
в `<имя>.assets`, в Markdown вставляется относительная ссылка. Отмена вставки не удаляет
уже созданный файл картинки. В переводе новая картинка остаётся в памяти до **Сохранить как…**.

## Одновременные изменения

Перед записью проверяются вкладка и исходная версия текста. Изменения в разных строках
сливаются автоматически. Если правки пересеклись, запись останавливается и появляется
**Разобрать конфликт**: можно выбрать вариант из исходника, из редактора или отредактировать
итог вручную. Изменения применяются после выбора всех конфликтующих фрагментов.
Запоздавший ответ от предыдущей вкладки не записывается в новый документ.

Если файл изменён другой программой, **Ctrl+S** из визуального редактора не перезаписывает его молча.
Сначала согласуйте изменение в Notepad++; несохранённые визуальные правки остаются в буфере.
Сохранение через меню самого Notepad++ использует его штатное поведение.

## Перевод

Переведённый документ — отдельный редактируемый черновик. Правки оригинала и перевода
не синхронизируются друг с другом. Доступна только кнопка **Сохранить как…**;
выбрать файл оригинала нельзя. При сохранении в другую папку относительные Markdown-ссылки
пересчитываются, чтобы продолжать указывать на прежние документы и изображения.
URL внутри существующего HTML остаются как в исходнике: HTML не переписывается.

**Оригинал** возвращает исходный документ, **Перевод** — сохранённый в памяти черновик.
**Перевести заново** запрашивает подтверждение замены черновика; неудачный запрос
сохраняет прежний текст. Каждый открытый документ имеет собственный черновик.
Они живут только в текущем сеансе Notepad++: сохраните нужный результат перед выходом.

Кодировка оригинала и его переводы строк сохраняются. Если выбранная кодировка
не поддерживает введённый символ, запись отклоняется с ошибкой; исходник не повреждается.
Новый файл перевода записывается в UTF-8 без BOM.
